주요 기능

그리기

펜과 연필, 라이브 도형, 텍스트를 사용하세요. 직접 선택 도구로 경로의 개별 점을 편집합니다.

레이어와 불리언

개체를 레이어로 정리하세요. 패스파인더 연산은 마스크를 쌓는 대신 실제 기하로 도형을 합쳐 새 경로를 만듭니다.

안내선과 스냅

눈금자에서 안내선을 끌어냅니다. 안내선 배치는 실행 취소 한 번으로 적용되고, 개체를 옮길 때 스냅 선이 안내선에 맞춰집니다.

내보내기

SVG, PNG, PDF, .ai 파일로 저장합니다. PDF는 페이지 안의 라이브러리 없이 앱이 직접 만듭니다.

저장과 보내기

이 기기의 Slop Drive에 저장하고, SVG나 PNG를 PhotoSlop 같은 다른 Slopographic 앱으로 보낼 수 있습니다.

SlopVector와 일반 데스크톱 벡터 편집기 비교

기능별로 비교합니다. 오른쪽 열은 일반적인 데스크톱 벡터 편집기가 보통 포함하는 기능을 설명합니다. 에디션, 추가 기능, 버전마다 다르므로 특정 제품은 제조사의 목록을 확인하세요.

개인정보 보호

아무것도 업로드되지 않습니다. 계정도 없습니다. 그림은 이 브라우저에 남고, Slop Drive는 기기에 보관합니다. 소유자가 설정에서 켜지 않는 한 추적은 실행되지 않습니다.

아직 할 수 없는 것

  • 단일 파일 오프라인 다운로드는 현재 오프라인 빌더가 인라인으로 넣을 수 없는 module 스크립트 태그 때문에 작동하지 않습니다. 호스팅된 앱은 작동합니다. 수정 작업이 진행 중입니다.
  • 텍스트 개체의 채우기 색, 글꼴, 크기 또는 정렬을 바꾸면 캔버스가 갱신되지 않을 수 있습니다. 알려진 버그이며 확인 중입니다.
  • 레이어를 더블클릭해도 옵션 대화 상자가 아직 열리지 않아, 레이어별 채우기, 획, 드롭 섀도, 흐림 효과는 쓸 수 없습니다.
  • 캔버스의 텍스트를 더블클릭해도 아직 편집되지 않으며, 그룹을 더블클릭해도 격리 모드로 들어가지 않습니다.
