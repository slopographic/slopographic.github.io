주요 기능

스캔되는 바코드

Code 128, EAN/UPC부터 GS1-128, QR Code, GS1 DataMatrix, Aztec까지 17가지 바코드 체계를 지원합니다. 검사 숫자는 자동으로 추가되며, 잘못된 입력에는 알기 쉬운 메시지가 나타납니다.

데이터 병합

CSV, TSV, JSON 또는 Excel(.xlsx) 레코드를 불러와 열을 필드에 연결하고, 수량 열에 따라 레코드마다 라벨을 인쇄하세요. 카운터, 날짜, 입력 프롬프트, 수식이 나머지를 채웁니다.

시트와 롤

Avery Letter와 Herma A4 시트, 그리고 2 × 1인치부터 100 × 150mm까지의 감열 롤 크기를 지원합니다. 시트 중간부터 시작할 수 있고, 인쇄하기 전에 페이지 미리 보기를 확인하세요.

인쇄와 내보내기

브라우저에서 정확한 페이지 크기로 인쇄하거나 PDF, PNG, SVG, ZPL II, EPL2, TSPL로 내보내세요. ZPL 파일을 열면 그 파일이 설명하는 라벨을 볼 수 있습니다.

양식 공유, 오프라인 작업

인쇄 양식 링크를 공유하면 다른 사람이 입력 프롬프트를 채우고 인쇄할 수 있으며, 디자이너 화면은 보이지 않습니다. 앱 전체를 오프라인에서 작동하는 HTML 파일 하나로 내려받을 수 있습니다. 프로젝트는 이 기기의 Slop Drive에 보관할 수 있습니다.

개인정보 보호

아무것도 업로드되지 않습니다. 계정도 없습니다. 라벨, 데이터, 프로젝트는 이 브라우저에 남고, Slop Drive는 이 기기에 보관합니다. 소유자가 설정에서 켜지 않는 한 추적은 실행되지 않습니다.

아직 할 수 없는 것

  • 실제 프린터 장비에서는 아직 확인하지 않았습니다. GS1 DataMatrix의 ZPL 출력, QR 위치, ITF 베어러 바, TSPL과 EPL 비트맵 극성은 프린터 테스트가 필요합니다.
  • 브라우저에서 프린터로 직접 인쇄할 수는 없습니다. PDF나 ZPL 출력을 프린터 자체 소프트웨어와 함께 사용하세요.
  • UPC-E, GS1 QR, 회전된 QR, 직사각형 Data Matrix는 그래픽으로 ZPL에 들어갑니다. 올바르게 해독되지만 출력이 더 크고, ^B9 출력은 프린터 확인이 필요합니다.
  • 텍스트는 캔버스가 아니라 속성 패널에서 편집합니다.
  • 회전은 90° 단위로만 가능합니다.
  • 다른 라벨 소프트웨어의 독점 형식 템플릿은 가져오지 않습니다.
  • 베타: 앱은 처음부터 끝까지 작동하지만 아직 테스트 중입니다.
