Ce qu’elle fait

Supprimer l’arrière-plan

Une étape transforme une photo en masque de détourage. Le modèle tourne dans votre navigateur : l’image ne quitte jamais votre appareil.

Trois modèles

Rapide pour les petits travaux, Qualité pour les détails fins, et Portrait pour les personnes. Le navigateur garde chaque modèle en cache après son premier chargement.

Affiner le contour (prévu)

Un pinceau et des réglages de contour progressif pour les cheveux et les autres contours fins. Pas encore réalisé.

Remplacer l’arrière-plan (prévu)

Transparent, une couleur, un flou ou une autre image, avec une ombre facultative. Pas encore réalisé.

Traitement par lot (prévu)

Traitez une file d’images et exportez-les les unes après les autres. Pas encore réalisé.

Confidentialité

Le moteur traite les images sur votre appareil, avec des modèles livrés avec le site. L’application finie est conçue de la même façon : rien n’est envoyé et il n’y a pas de compte. Aucun suivi ne fonctionne, sauf si le propriétaire l’a activé dans Paramètres.

Ce qu’elle ne peut pas encore faire

  • L’application ne fonctionne pas encore : sa page charge des scripts qui ne sont pas encore écrits. Utilisez le lien ci-dessus seulement pour suivre l’avancement.
  • Pas encore réalisés : le pinceau d’affinage, le remplacement d’arrière-plan, l’export, le traitement par lot, les menus et l’intégration à Slop Drive.
  • La voie GPU (WebGPU) n’a pas été testée sur de vraies cartes graphiques. La voie CPU est utilisée quand aucun GPU adapté n’est trouvé.
  • Le modèle Qualité est lent sur les grandes images. Lors des tests, il a pris de 45 à 70 secondes pour une image de 1024 pixels sur une machine chargée.
  • Pas encore d’intégration à PhotoSlop. Une commande Supprimer l’arrière-plan est prévue.
