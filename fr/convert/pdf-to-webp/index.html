Convertisseur PDF vers WebP

Obtenez les pages d’un PDF en petites images WebP pour un site web ou une discussion.

Accepte

Documents PDF (.pdf). Les PDF protégés par mot de passe sont refusés. Les autres types de fichiers ne sont pas convertis sur cette page ; le centre File convert prend tous les types qu’il connaît.

Comment convertir

  1. Chaque page est dessinée en image à la résolution choisie (étape 1) ; saisissez une plage de pages pour n’en obtenir que certaines.
  2. Chaque image est ensuite enregistrée en WebP (étape 2) avec la qualité et la taille choisies. Téléchargez-les une à une ou toutes en ZIP.

Vos fichiers restent sur cet appareil. Rien n’est envoyé : la conversion tourne dans votre navigateur, et le fichier n’est jamais envoyé à Slopographic ni à un autre serveur.

Questions

Pourquoi le WebP ?

Les images WebP sont souvent un tiers plus légères que le PNG ou le JPG à rendu égal, et tous les navigateurs actuels les affichent.

Puis-je garder le fichier intermédiaire ?

Oui. Ouvrez Options et cochez Garder aussi les fichiers intermédiaires : il est listé avec le résultat.

Mes fichiers sont-ils envoyés ?

Non. Les deux étapes se font dans votre navigateur, sur cet appareil. Vos fichiers ne sont envoyés ni à Slopographic ni à un autre serveur.
