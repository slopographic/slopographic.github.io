File convert

Décodeur Base64 vers un fichier

Transformez un texte Base64 en fichier. Le type est détecté à partir des octets : un PNG décodé reçoit donc un nom en .png.

Fonctionnement

Les espaces et les sauts de ligne sont ignorés. Les préfixes d’URL data: sont retirés. Les octets décodés sont comparés à une signature de fichier connue pour choisir l’extension.

Vos fichiers restent sur cet appareil. Rien n’est envoyé, et le convertisseur tourne entièrement dans votre navigateur.

Questions

Pourquoi le fichier décodé a-t-il un nom étrange ?

Les noms viennent du fichier d’entrée. Renommez le fichier de sortie si vous en voulez un précis.

Que faire si le décodage échoue ?

Le texte contient des caractères hors Base64, ou sa longueur est incorrecte. Vérifiez la copie.

Mes fichiers sont-ils envoyés ?

Non. Chaque conversion tourne dans votre navigateur, sur cet appareil. Les fichiers ne sont envoyés ni à Slopographic ni à aucun autre serveur.
