Prüfung

So funktioniert Slopographic

Die Apps laufen in Ihrem Browser. Diese Seite listet die Browserfunktionen auf, die sie nutzen, jede Netzwerkanfrage, die sie stellen können, und was auf Ihrem Gerät gespeichert wird, damit Sie jede Aussage selbst prüfen können. Jede Aussage hier wurde am Quellcode im öffentlichen Repository geprüft.

Die Kurzfassung

  • Ihre Dateien bleiben auf Ihrem Gerät. Die Apps haben keinen Server, der sie empfängt, und kein Code lädt eine Datei hoch, die Sie öffnen oder speichern. Die einzige Ausnahme ist eine Kopie, die Sie der KI-Schaltfläche erlauben, an einen KI-Dienst zu senden, den Sie selbst verbunden haben.
  • Dateien, die Sie auf der Festplatte auswählen, werden über die File System Access API des Browsers gelesen und geschrieben, in den Ordnern, die Sie wählen. Siehe die Browser-APIs.
  • Daten werden im eigenen Speicher des Browsers auf diesem Gerät gehalten (IndexedDB und localStorage). Siehe was gespeichert wird.
  • Einige Anfragen verlassen die Website, aber nur in den Fällen, die unter jede ausgehende Anfrage aufgeführt sind: ein Download, den Sie bestätigen, ein Cloud-Backup, das Sie verbinden, ein KI-Dienst, den Sie mit Ihrem eigenen Schlüssel verbinden, die Wechselkurse, die Sie einschalten, sowie Analysen oder Werbung, denen Sie zustimmen.
  • Die KI-Schaltfläche arbeitet mit einem Modell auf Ihrem Gerät, mit einem Server auf Ihrem eigenen Computer wie Ollama oder LM Studio oder mit Ihrem eigenen Schlüssel für einen Dienst wie Claude, ChatGPT oder Gemini. Mit einem Schlüssel gehen Ihre Anfragen direkt vom Browser zu diesem Anbieter. Siehe die KI-Schaltfläche.
  • Die Startseite lädt bei jedem Besuch den Google-Analytics-Code, wobei Analysen auf verweigert gesetzt sind. Andere Seiten laden ihn erst, nachdem Sie Analysen akzeptiert haben. Werbung wird erst geladen, nachdem Sie Werbung akzeptiert haben.

Einfach erklärt

Wohin gehen meine Dateien?

Nirgendwohin. Wenn Sie ein Foto, eine PDF oder eine Tabelle öffnen, liest die App sie in diesem Browser-Tab. Es gibt keinen Upload-Schritt und keinen Slopographic-Server, der sie empfangen könnte. Was Sie speichern, landet auf Ihrer eigenen Festplatte oder im Speicher dieses Browsers auf diesem Gerät. Nur wenn Sie einen KI-Dienst mit Ihrem eigenen Schlüssel verbinden und es erlauben, geht eine Kopie an diesen Dienst (siehe die KI-Schaltfläche).

Warum lädt eine App manchmal etwas herunter?

Manche Funktionen brauchen eine große Datei, die die meisten Menschen nie nutzen: ein KI-Modell (um einen Hintergrund zu entfernen, Text zu erkennen oder Sprache zu transkribieren), die Videoengine (um ein Video zu konvertieren) oder eine Schrift für ein anderes Schriftsystem. Diese werden nur geladen, wenn Sie die Funktion nutzen, nachdem die App Ihnen gesagt hat, was es ist und wie groß es ist. Sie bleiben im Browser gespeichert, damit es nur einmal geschieht. Ihre eigenen Dateien sind nie Teil dieser Anfrage.

Funktioniert es offline?

Ja, nach dem ersten Besuch. Die eigenen Dateien der Website werden vom Browser gespeichert, daher öffnen und funktionieren die Apps ohne Verbindung. Nur ein Download, den Sie noch nicht gemacht haben (ein Modell oder eine Schrift), braucht das Netz.

Muss ich etwas installieren?

Nein. Öffnen Sie einfach eine App im Browser auf Ihrem Smartphone, Tablet oder Computer und legen Sie los. Nach Ihrem ersten Besuch funktioniert sie auch ohne Internet weiter. Möchten Sie ein Symbol auf Ihrem Startbildschirm? Auf dem iPhone oder iPad tippen Sie auf Teilen und dann auf Zum Home-Bildschirm. Auf Android öffnen Sie das Browsermenü und tippen auf Zum Startbildschirm hinzufügen. Auf einem Computer klicken Sie auf das Installationssymbol in der Adresszeile. Sie brauchen weder den App Store noch Google Play, und Ihre Dateien bleiben auf Ihrem Gerät.

Was sendet die KI-Schaltfläche, und wohin?

Das hängt vom gewählten Modell ab. Ein Modell auf Ihrem Gerät (es braucht WebGPU und wird einmal heruntergeladen) antwortet in diesem Tab, und nichts, was Sie fragen, verlässt das Gerät. Ollama, LM Studio und ähnliche Server laufen auf Ihrem eigenen Computer oder auf einem in Ihrem Netzwerk, den Sie eingerichtet haben. Mit Ihrem eigenen Schlüssel für einen Dienst wie Claude, ChatGPT, Gemini, OpenRouter oder Groq gehen Ihre Nachrichten direkt vom Browser zu diesem Anbieter, ohne einen Slopographic-Server dazwischen, und es gelten dessen Bedingungen und Preise. Eine Kopie einer Datei oder eines Bildes Ihrer Arbeit wird erst gesendet, nachdem das Panel fragt und Sie zustimmen. Sie können für eine Anfrage, für einen Besuch oder dauerhaft zustimmen und dies in den KI-Berechtigungen wieder zurücknehmen. Bilder, die durch KI erzeugt oder verändert werden (Bild erzeugen, Mit KI bearbeiten), brauchen einen Bilddienst, den Sie verbinden, etwa OpenAI, Gemini oder OpenRouter mit Ihrem eigenen Schlüssel: Im Browser selbst entsteht kein Bild. Modelle auf Ihrem Gerät und auf Ihrem eigenen Computer kosten nichts. Gemini, Groq und Mistral haben kostenlose Kontingente, und OpenRouter hat kostenlose Modelle (das Panel markiert sie mit Frei). Ein Schlüssel bleibt in diesem Tab, bis Sie ihn schließen, oder nur dann in diesem Browser, wenn Sie Auf diesem Gerät merken ankreuzen. Für OpenRouter können Sie auch auf Mit OpenRouter anmelden drücken, statt einen Schlüssel einzufügen: Ihr Browser geht zu openrouter.ai, Sie erlauben dort den Zugriff, und bei der Rückkehr fragt diese Seite OpenRouter selbst nach einem Schlüssel für diesen Browser. Die Anmeldung läuft direkt zwischen Ihrem Browser und OpenRouter, und nichts geht über Slopographic-Server. Der Schlüssel wird aus Ihrem eigenen OpenRouter-Guthaben bezahlt und genauso gespeichert wie ein eingefügter; Sie können ihn unter openrouter.ai/settings/keys begrenzen oder widerrufen, und Schlüssel vergessen entfernt ihn aus diesem Browser.

Kann ein KI-Agent die Apps nutzen?

In einem Browser, der WebMCP unterstützt, ja: Ein Assistent im Browser oder ein Agent auf Ihrem Computer, der über eine Browser-Erweiterung verbunden ist, kann Befehle einer App, Konvertierungen von File convert und Workflows ausführen sowie Dateien öffnen, speichern oder herunterladen. Er spricht Ihre Dateien über IDs an; die Arbeit läuft in diesem Tab, und die Apps laden nichts hoch, auch wenn der Agent sieht, was die Werkzeuge zurückmelden. Alles, was Ihre Arbeit löscht oder ersetzt, fragt vorher nach. WebMCP ist ein früher Entwurf: Chrome hat es als Test (Versionen 149 bis 156) und hinter einem Flag, Edge hinter einem Flag, Firefox und Safari noch nicht. Schalten Sie es in den Einstellungen oder unter Hilfe, KI-Agenten aus.

Kann ich das selbst prüfen?

Ja. Der Quellcode ist öffentlich, und die Abschnitte unten listen jede Browserfunktion auf, die die Apps nutzen, und jede Anfrage, die sie stellen können, mit der Datei, die sie auslöst. Sie können außerdem die Entwicklerwerkzeuge Ihres Browsers öffnen, zum Reiter Netzwerk gehen und zusehen: Das Öffnen und Speichern Ihrer Dateien sendet nichts.

Slopographic aus Claude Code und anderen KI-Apps nutzen

Demnächst: Eine KI-App auf Ihrem Computer, etwa Claude Code, Codex, Cursor, VS Code oder Claude Desktop, kann die Slopographic-App nutzen, die in Ihrem Browser geöffnet ist: ihre echten Befehle, Konvertierungen und Workflows, wobei Ihre Dateien hineingehen und Ergebnisse als Dateien auf Ihrem Computer herauskommen. Das läuft über den Slopographic-MCP-Server, ein kleines Programm, das die KI-App auf Ihrem Computer startet. Es braucht kein Konto und keine Installation außer der KI-App selbst.

  1. Claude Code: Geben Sie /plugin marketplace add slopographic/claude-plugin ein, dann /plugin install slopographic@slopographic. Das machen Sie einmal.
  2. Geben Sie /slopographic:slop-connect ein (fügen Sie auf Wunsch einen App-Namen hinzu, etwa photoslop). Claude Code öffnet Slopographic in Ihrem Browser und zeigt einen kurzen Code.
  3. Chrome fragt einmal, ob diese Website Apps und Dienste auf diesem Gerät nutzen darf. Wählen Sie Zulassen: So erreicht die Seite Claude Code auf Ihrem Computer. Die Seite spricht nur mit Ihrem eigenen Computer (127.0.0.1), nicht mit Ihrem Netzwerk.
  4. Geben Sie den Code auf der Seite ein. Die Seite zeigt dann in der Ecke „Claude Code ist verbunden · Trennen“. Drücken Sie Trennen oder schließen Sie den Tab, um die Verbindung zu beenden.

Jeder Tab wird einzeln gekoppelt, und der Code funktioniert nur einmal. Ohne ihn kann nichts anderes auf Ihrem Computer die Seite nutzen. Aktionen, die Ihre Arbeit löschen oder ersetzen, fragen Sie weiterhin auf der Seite, wie im KI-Panel. Jede Slopographic-Seite kann sich über die Befehlspalette verbinden: Strg+K (⌘K auf dem Mac), dann „KI-App verbinden …“.

Die Einrichtung für andere KI-Apps (Codex, Gemini CLI, Cursor, VS Code, Windsurf, Claude Desktop) erscheint hier, sobald die Skripte laufen.

ChatGPT-Chats können nur Server im Internet erreichen und deshalb diesen lokalen Server noch nicht nutzen. Codex in der ChatGPT-Desktop-App kann es.

Cookies und Analysen

  • Vom Code der Website gespeichert: eine Einwilligung im localStorage (slop-consent), wobei Analysen, Werbung und Kurse auf aus stehen, bis Sie wählen. Der Speicher lässt sich jederzeit im Browser löschen.
  • Nicht vom Code der Website gespeichert: kein Cookie und kein Konto. Das Repository setzt nie ein Cookie.
  • Google Analytics: Auf der Startseite wird das Tag mit analytics_storage auf verweigert geladen. Es wird nur eingeschaltet, wenn Sie Analysen akzeptieren. Auf anderen Seiten lädt es erst, nachdem Sie zugestimmt haben.
  • Die eigenen Skripte von Google können beim Ausführen eigene Cookies setzen. Das entscheidet Google, nicht der Code von Slopographic. Die Prüfschritte unten zeigen, was der Browser tatsächlich speichert.
  • Werbung: AdSense lädt erst, nachdem Sie Werbung akzeptiert haben. Wenn Sie Werbung ablehnen, bleiben die Anzeigenplätze leer.

Offline arbeiten

Nach einem Besuch werden die eigenen Dateien der Website vom Service Worker im Cache Storage gespeichert (service-worker.js, mit seiner Dateiliste in sw-precache.js). Seiten werden zuerst über das Netz geprüft, dann aus dem Cache geladen, und danach wird die Offline-Seite angezeigt. Ihre Dateien sind nicht im Cache des Service Workers: Sie liegen im Ordner, den Sie gewählt haben, oder in IndexedDB. Die Apps funktionieren weiter, wenn das Netz aus ist. Downloads (die oben genannten Modelle und Schriftpakete) brauchen beim ersten Mal das Netz.

So prüfen Sie es selbst

  1. Reiter Netzwerk, bei geladener Seite. Öffnen Sie die App, drücken Sie F12 (oder Cmd+Option+I auf dem Mac) und öffnen Sie den Reiter Netzwerk. Aktivieren Sie „Protokoll beibehalten“ und laden Sie neu. Lesen Sie die Spalte Domain. Bei einem einfachen Besuch sollten Sie nur slopographic.com sehen, auf der Startseite zusätzlich Googles Analyse-Domains.
  2. Reiter Netzwerk, offline. Öffnen Sie im Reiter Netzwerk das Drosselungsmenü und wählen Sie Offline. Laden Sie neu, öffnen Sie dann eine Datei, bearbeiten und speichern Sie sie. Die App sollte funktionieren. Alles, was einen Download braucht, sagt das.
  3. Reiter Anwendung, Speicher. Öffnen Sie in Chrome oder Edge den Reiter Anwendung. Unter Speicher finden Sie Local Storage, Session Storage, IndexedDB, Cookies, Cache Storage und Service Worker. Vergleichen Sie, was Sie sehen, mit den Tabellen auf dieser Seite.
  4. Akzeptieren oder ablehnen, dann vergleichen. Lehnen Sie Analysen und Werbung im Einwilligungsstreifen ab, laden Sie neu und prüfen Sie den Reiter Netzwerk erneut. Akzeptieren Sie sie dann und sehen Sie, welche Anfragen erscheinen.
  5. Den Quellcode lesen. Der Code ist öffentlich im Slopographic-Repository auf GitHub. Suchen Sie darin nach fetch(, indexedDB.open, localStorage oder showDirectoryPicker, um jede Zeile dieser Seite zu bestätigen. Der Einwilligungscode steht in shared/consent/, die Cloud-Synchronisierung in shared/sync/ und die Download-Listen in shared/library/ und aitools/.

Lokale Ordner (die File System Access API) brauchen Chrome oder Edge. Firefox und Safari bieten sie nicht an; die Apps sagen das dort, wo es zutrifft.
