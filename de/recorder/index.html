Der Browser fragt immer, bevor er einen Bildschirm, eine Kamera oder ein Mikrofon freigibt, und zeigt an, dass aufgenommen wird. Es wird nichts hochgeladen: Die Aufnahme entsteht und wird auf diesem Gerät gespeichert.

MP4 und GIF werden von der Video-Engine auf diesem Gerät erstellt. Sie wird beim ersten Mal einmalig geladen (etwa 32 MB).
