Was sie kann

Seiten

Dateien zusammenführen, Seiten per Ziehen neu ordnen, drehen, duplizieren, löschen und nach Bereichen, nach je N Seiten oder in einzelne Dateien teilen. Rückgängig gilt für jede Änderung.

Kommentieren und unterschreiben

Fügen Sie Text, Stift, Markierungsstift, Formen, Bilder und Unterschriften hinzu. Zeichnen Sie eine Unterschrift, tippen Sie eine ein, oder bewahren Sie eine gespeicherte Unterschrift in diesem Browser auf.

Formulare und Kennwörter

Füllen Sie Text-, Kontrollkästchen-, Dropdown- und Optionsfelder aus und behalten Sie sie bearbeitbar oder machen Sie sie fest (reduzieren). Öffnen Sie kennwortgeschützte Dateien mit RC4- oder AES-Verschlüsselung.

Schwärzen

Markieren Sie Bereiche von Hand oder suchen Sie nach Text, Mustern und Vorgaben wie E-Mail-Adressen und Kartennummern. Beim Anwenden einer Schwärzung wird alles unter dem Kasten aus der gespeicherten Datei entfernt.

Komprimieren und konvertieren

Komprimieren Sie eine Datei, exportieren Sie Seiten als PNG oder JPEG, erstellen Sie eine PDF aus Bildern und extrahieren Sie den Text.

Datenschutz

Nichts wird hochgeladen. Es gibt keine Konten. Ihre PDFs, Anmerkungen und gespeicherten Unterschriften bleiben in diesem Browser, und Slop Drive bewahrt Dateien auf diesem Gerät auf. Es läuft kein Tracking, außer der Betreiber hat es unter Einstellungen eingeschaltet.

Was sie noch nicht kann

  • Vorhandenen Text in einer PDF können Sie nicht bearbeiten. Text kann als Anmerkung hinzugefügt werden.
  • Lesezeichen, Gliederungen und getaggte Struktur werden nicht in die gespeicherte Datei übernommen.
  • Text, der mit den Standardschriften hinzugefügt wird, kann keine Zeichen außerhalb des westlichen Zeichensatzes (CJK, Emoji) anzeigen; sie erscheinen als „?“. Der Offline-Datei fehlen außerdem einige Schriften, daher können CJK-PDFs ohne eingebettete Schriften Ersatzglyphen verwenden.
  • Geschwärzte Seiten werden als Bilder gespeichert, daher ist ihr Text nicht mehr durchsuchbar. Es gibt keinen Modus, der den Text erhält.
  • Beim Seitenwechsel kann die vorherige Seite etwa 150 ms lang zu sehen sein, bevor die neue gezeichnet wird. Beim Öffnen der Seitenansicht kann außerdem kurz weiß aufblitzen. Eine Korrektur ist geplant.
  • Ein Bericht eines Betreibers über leere Seiten nach dem Hinzufügen von Inhalten wurde noch nicht reproduziert. Die Untersuchung läuft noch.
