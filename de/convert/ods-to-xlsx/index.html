Konverter: ODS zu XLSX

Eine LibreOffice-Calc-Datei an jemanden mit Excel schicken: Jedes Blatt wird zu einem Excel-Blatt.

Akzeptiert

OpenDocument-Tabelle (.ods). Andere Dateitypen werden auf dieser Seite nicht umgewandelt; der File-convert-Hub nimmt jede Art, die er kennt.

So konvertieren Sie

  1. Die ODS-Datei wird vom selben Leser gelesen wie bei Slop Tables, und jedes Blatt wird in eine XLSX-Datei geschrieben, mit seinen Werten, fetten Zellen und Zahlen- und Datumsformaten.
  2. Formeln werden als die Werte geschrieben, die sie anzeigten; Diagramme und Bilder werden nicht übernommen.

Ihre Dateien bleiben auf diesem Gerät. Nichts wird hochgeladen: Die Konvertierung läuft in Ihrem Browser, und die Datei wird nie an Slopographic oder an einen anderen Server gesendet.

Fragen

Öffnet es sich in Excel?

Ja. Es ist eine übliche XLSX-Arbeitsmappe.

Werden meine Dateien hochgeladen?

Nein. Die Umwandlung läuft in Ihrem Browser auf diesem Gerät. Ihre Dateien werden nicht an Slopographic oder an einen anderen Server gesendet.
