Konverter: SBV zu SRT (YouTube-Untertitel)

YouTube Studio lädt Untertitel als .sbv herunter. Wandeln Sie sie in SRT um, das fast jeder Player und jeder Editor liest.

Akzeptiert

YouTube-Untertitel (SBV) (.sbv). Andere Dateitypen werden auf dieser Seite nicht umgewandelt; der File-convert-Hub nimmt jede Art, die er kennt.

So konvertieren Sie

  1. Jeder Untertitel behält Start, Ende und Text; die Zeiten werden im SRT-Format geschrieben, und die Untertitel werden ab 1 nummeriert.
  2. Verschieben Sie die Zeit um eine Anzahl Sekunden (negativ für früher), wenn die Untertitel vorauseilen oder nachhinken.

Ihre Dateien bleiben auf diesem Gerät. Nichts wird hochgeladen: Die Konvertierung läuft in Ihrem Browser, und die Datei wird nie an Slopographic oder an einen anderen Server gesendet.

Fragen

Und dann zu VTT?

Ja. Eine SBV-Datei bekommt VTT unter Weitere Formate im Menü Konvertieren, über SRT.

Kann ich tippen oder einfügen statt eine Datei zu nehmen?

Ja. Tippen oder fügen Sie in das Feld unter dem Konverter ein, und die Vorschau aktualisiert sich beim Tippen.

Werden meine Dateien hochgeladen?

Nein. Die Umwandlung läuft in Ihrem Browser auf diesem Gerät. Ihre Dateien werden nicht an Slopographic oder an einen anderen Server gesendet.
