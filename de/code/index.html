      Eine Datei aus Slop Drive öffnen

      Eine Datei zum Bearbeiten wählen oder eine neue anlegen. Änderungen werden auf diesem Gerät automatisch gespeichert, bis gespeichert wird; „Speichern“ schreibt in dieselbe Slop-Drive-Datei zurück.
