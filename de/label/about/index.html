Gestalten Sie Strichcode-Etiketten, führen Sie eine Tabelle damit zusammen und drucken oder exportieren Sie. Alles bleibt in Ihrem Browser.

Was sie kann

Strichcodes, die sich scannen lassen

Siebzehn Symbologien, von Code 128 und EAN/UPC bis GS1-128, QR-Code, GS1 DataMatrix und Aztec. Prüfziffern werden für Sie ergänzt, und fehlerhafte Eingaben erhalten eine verständliche Meldung.

Datenzusammenführung

Laden Sie Datensätze aus CSV, TSV, JSON oder Excel (.xlsx), ordnen Sie Spalten Feldern zu und drucken Sie ein Etikett pro Datensatz, mit einer Mengenspalte. Zähler, Datumsangaben, Abfragen und Formeln füllen den Rest.

Bögen und Rollen

Avery-Letter- und Herma-A4-Bögen sowie Thermorollen von 2 × 1 Zoll bis 100 × 150 mm. Beginnen Sie einen Bogen an einer beliebigen Stelle, und prüfen Sie die Seitenvorschau, bevor Sie drucken.

Drucken und exportieren

Drucken Sie aus dem Browser in exakter Seitengröße, oder exportieren Sie PDF, PNG, SVG, ZPL II, EPL2 und TSPL. Öffnen Sie eine ZPL-Datei, um das Etikett zu sehen, das sie beschreibt.

Formular teilen, offline arbeiten

Teilen Sie einen Link zu einem Druckformular, damit jemand die Abfragen ausfüllen und drucken kann, ohne den Designer zu sehen. Laden Sie die ganze App als eine HTML-Datei herunter, die offline funktioniert. Projekte können auf diesem Gerät in Slop Drive liegen.

Datenschutz

Nichts wird hochgeladen. Es gibt keine Konten. Etiketten, Daten und Projekte bleiben in diesem Browser. Slop Drive bewahrt sie auf diesem Gerät auf. Es läuft kein Tracking, außer der Betreiber hat es unter Einstellungen eingeschaltet.

Was sie noch nicht kann

  • Noch nicht auf echter Druckerhardware geprüft. Die ZPL-Ausgabe für GS1 DataMatrix, die Position des QR-Codes, die Tragebalken bei ITF sowie die Bitmap-Polarität bei TSPL und EPL brauchen noch einen Drucktest.
  • Kein direktes Drucken vom Browser an einen Drucker. Verwenden Sie die PDF- oder ZPL-Ausgabe mit der Software Ihres Druckers.
  • UPC-E, GS1-QR, gedrehte QR-Codes und rechteckige Data Matrix gehen als Grafiken nach ZPL. Sie werden korrekt gelesen, aber die Ausgabe ist größer, und die Ausgabe mit ^B9 muss an einem Drucker geprüft werden.
  • Text wird im Eigenschaften-Bedienfeld bearbeitet, nicht auf der Zeichenfläche.
  • Drehung nur in 90°-Schritten.
  • Vorlagen aus den proprietären Formaten anderer Etikettensoftware werden nicht importiert.
  • Beta: Die App funktioniert durchgängig, wird aber noch getestet.
