功能介紹

頁面

合併檔案、拖曳重新排序頁面、旋轉、複製、刪除，並可依頁數範圍、每 N 頁或分成多個檔案來分割。復原功能涵蓋每一項變更。

加註與簽署

可加入文字、畫筆、螢光筆、形狀、圖片與簽名。可以手寫簽名、輸入簽名，或保留此瀏覽器中已存的簽名。

表單與密碼

可填寫文字、核取方塊、下拉式與選項按鈕欄位，並可保留為可編輯或扁平化。可開啟以 RC4 或 AES 加密、有密碼保護的檔案。

塗黑

可手動標記區域，或搜尋文字、樣式與預設值，例如電子郵件地址與卡號。套用塗黑後，框內的內容會從儲存的檔案中移除。

壓縮與轉換

壓縮檔案、將頁面匯出為 PNG 或 JPEG、由圖片製作 PDF，並擷取文字。

隱私權

不會上傳任何內容。沒有帳戶。您的 PDF、加註與已存的簽名會留在此瀏覽器中，Slop Drive 則把檔案保存在此裝置上。除非擁有者已在 設定中開啟，否則不會執行任何追蹤。

目前尚無法做到的事

  • 您無法編輯 PDF 中既有的文字。只能以加註的方式新增文字。
  • 書籤、大綱與標籤結構不會保留到儲存的檔案中。
  • 使用標準字型新增的文字無法顯示西文字元以外的字（中日韓文字、表情符號），會顯示為「?」。離線檔案也缺少部分字型，因此未嵌入字型的中日韓 PDF 可能會使用替代字形。
  • 經過塗黑的頁面會以圖片儲存，因此其中的文字無法再搜尋。目前沒有可保留文字的模式。
  • 切換頁面時，新頁面繪製前，上一頁可能會顯示約 150 毫秒。開啟頁面檢視時，畫面也可能短暫閃白。修正工作已在規劃中。
  • 擁有者曾回報新增內容後出現空白頁面，目前尚未重現，調查仍在進行中。
