File convert

vCard 轉 Excel（XLSX）轉換器

將 .vcf 通訊錄轉為 Excel 活頁簿，每位聯絡人佔一列。

支援格式

vCard（.vcf）。本頁不轉換其他檔案類型。

如何轉換

  1. 拖入一個或多個 vCard 檔案（.vcf）。檔案中的每位聯絡人都會成為一列。
  2. 選擇「轉換為 XLSX」。欄位包括 Name、First name、Last name、Organisation、Job title、E-mail、Phone、Address、Website 與 Note。
  3. 下載活頁簿。可在 Excel、LibreOffice 或 Slop Tables 中開啟，進行排序、篩選或列印。

您的檔案會留在此裝置上。不會上傳任何內容：轉換在您的瀏覽器中完成，檔案絕不會傳送到 Slopographic 或其他任何伺服器。

常見問題

活頁簿有格式嗎？

沒有。數值儲存在名為 Sheet1 的單一工作表中，第一列是欄位名稱。

沒有姓名的聯絡人會保留嗎？

只要有其他欄位就會保留。沒有姓名的聯絡人會以其電子郵件或電話寫在第一欄，與 vCard 中的顯示方式相同。
