稽核

Slopographic 的運作方式

這些應用程式在您的瀏覽器中執行。本頁列出它們使用的瀏覽器功能、它們可能發出的每一項網路請求，以及保存在您裝置上的內容，讓您可以自行核對每項說明。本頁的每一句敘述，都已對照公開儲存庫中的原始碼檢查過。

簡短版本

  • 您的檔案會留在您的裝置上。應用程式沒有接收檔案的伺服器，也沒有任何程式碼會上傳您開啟或儲存的檔案。唯一的例外，是您允許 AI 按鈕把一份副本傳送到您自行連結的 AI 服務。
  • 您在磁碟上選取的檔案，是透過瀏覽器的 File System Access API 讀寫，位於您所選的資料夾中。參見 瀏覽器 API。
  • 資料保存在此裝置上瀏覽器自己的儲存空間中（IndexedDB 與 localStorage）。參見 保存的內容。
  • 部分請求會離開網站，但僅限於 所有對外請求中列出的情況：您確認的下載、您連結的雲端備份、您以自己的金鑰連結的 AI 服務、您開啟的匯率，以及您接受的分析或廣告。
  • AI 按鈕可使用您裝置上的模型、您自己電腦上的伺服器（例如 Ollama 或 LM Studio），或您自己的金鑰連接 Claude、ChatGPT 或 Gemini 等服務。使用金鑰時，您的提問會從瀏覽器直接送到該供應商。參見 AI 按鈕。
  • 首頁每次造訪都會載入 Google Analytics 程式碼，分析功能設為拒絕。其他頁面只有在您接受分析後才會載入。只有在您接受廣告後，廣告才會載入。

白話說明

我的檔案會去哪裡？

哪裡都不去。當您開啟照片、PDF 或試算表時，應用程式會在此瀏覽器分頁中讀取它。沒有上傳步驟，也沒有可以接收檔案的 Slopographic 伺服器。您儲存的內容會存到您自己的磁碟，或存到此裝置上此瀏覽器的儲存空間。只有當您以自己的金鑰連結 AI 服務並允許時，才會有副本傳送到該服務（參見 AI 按鈕）。

為什麼應用程式有時會下載東西？

部分功能需要大型檔案，而大多數人從未用到：AI 模型（用於移除背景、辨識文字或轉錄語音）、影片引擎（用於轉換影片），或其他書寫系統的字型。這些檔案只會在您使用該功能時才取得，而且是在應用程式告知檔案用途與大小之後，並保存在瀏覽器中，因此只需下載一次。您自己的檔案永遠不屬於這項請求的一部分。

可以離線使用嗎？

可以，首次造訪之後即可。網站自身的檔案會由瀏覽器保存，因此應用程式不連線也能開啟與使用。只有您尚未下載的內容（模型或字型）才需要網路。

需要安裝任何東西嗎？

不需要。只要在手機、平板或電腦的瀏覽器中開啟應用程式即可開始使用。首次造訪之後，即使沒有網際網路也能繼續使用。想在主畫面放上圖示嗎？在 iPhone 或 iPad 上，點選分享，再點選「加入主畫面」。在 Android 上，開啟瀏覽器選單並點選「新增至主畫面」。在電腦上，按一下網址列中的安裝圖示。您不需要 App Store 或 Google Play，您的檔案也會留在您的裝置上。

AI 按鈕會傳送什麼內容？傳到哪裡？

這取決於您選擇的模型。裝置上的模型（需要 WebGPU，且只需下載一次）會在此分頁內回答，您的提問不會離開裝置。Ollama、LM Studio 與類似的伺服器在您自己的電腦上執行，或在您設定好的網路中的某台電腦上執行。若您以自己的金鑰使用 Claude、ChatGPT、Gemini、OpenRouter 或 Groq 等服務，您的訊息會從瀏覽器直接送到該供應商，中間沒有 Slopographic 的伺服器，並適用其條款與價格。只有在面板詢問並且您允許之後，才會傳送檔案或您作品的圖片副本（您可以只允許單次請求、單次造訪，或永久允許，並可在 AI 權限中收回）。AI 製作或修改的圖片（生成圖片、以 AI 編輯）需要您連結的圖片服務，例如使用您自己金鑰的 OpenAI、Gemini 或 OpenRouter：瀏覽器本身無法繪製這些圖片。裝置上的模型與您自己電腦上的模型不需付費；Gemini、Groq 與 Mistral 有免費方案，OpenRouter 則提供免費模型（面板會標示為「免費」）。金鑰只會保留在此分頁中直到您關閉分頁，只有在您勾選「在此裝置上記住」時，才會保存在此瀏覽器中。使用 OpenRouter 時，您也可以不貼上金鑰，改按「以 OpenRouter 登入」：瀏覽器會前往 openrouter.ai，您在該處允許存取，返回時，本頁會直接向 OpenRouter 為此瀏覽器索取金鑰。登入過程直接發生在您的瀏覽器與 OpenRouter 之間，不會經過 Slopographic 的伺服器。費用由您自己的 OpenRouter 額度支付，金鑰的保存方式與貼上的金鑰完全相同；您可以在 openrouter.ai/settings/keys 設定上限或撤銷，而「忘記金鑰」會將它從此瀏覽器中移除。

AI 代理程式可以使用這些應用程式嗎？

在支援 WebMCP 的瀏覽器中可以：瀏覽器中的助理，或透過瀏覽器擴充功能連結到您電腦上的代理程式，可以執行應用程式的命令、File convert 轉換與工作流程，並開啟、儲存或下載檔案。它以 id 指稱您的檔案；工作在此分頁中執行，應用程式不上傳任何內容，但代理程式會看到工具回報的結果。任何會刪除或取代您作品的操作，都會先詢問您。WebMCP 仍是早期草案：Chrome 以試用版提供（版本 149 至 156），並且需要旗標才能使用；Edge 需要旗標；Firefox 與 Safari 尚未提供。可在設定中關閉，或在說明的「AI 代理程式」中關閉。

我可以自行核對嗎？

可以。原始碼是公開的，下方各節列出應用程式使用的每項瀏覽器功能、它可能發出的每項請求，以及製作該功能的檔案。您也可以開啟瀏覽器的開發人員工具，前往「網路」分頁並觀察：開啟與儲存您的檔案不會發出任何請求。

從 Claude Code 與其他 AI 應用程式使用 Slopographic

即將推出：您電腦上的 AI 應用程式，例如 Claude Code、Codex、Cursor、VS Code 或 Claude Desktop，可以使用您在瀏覽器中開啟的 Slopographic 應用程式：真正的命令、轉換與工作流程，您的檔案會送入，結果會以檔案形式回到您的電腦。它透過 Slopographic MCP 伺服器運作，這是 AI 應用程式在您的電腦上啟動的一個小程式。除了 AI 應用程式本身，不需要帳戶，也不需要安裝其他東西。

  1. Claude Code：輸入 /plugin marketplace add slopographic/claude-plugin，然後輸入 /plugin install slopographic@slopographic。只需做一次。
  2. 輸入 /slopographic:slop-connect（如果您願意，可以在後面加上應用程式名稱，例如 photoslop）。Claude Code 會在瀏覽器中開啟 Slopographic，並顯示一組簡短的代碼。
  3. Chrome 會詢問一次，是否允許此網站使用此裝置上的應用程式與服務。請選擇允許：頁面要靠它才能連上您電腦上的 Claude Code。頁面只會與您自己的電腦（127.0.0.1）通訊，不會連到您的網路。
  4. 在頁面中輸入代碼。頁面隨後會在角落顯示「Claude Code 已連結 · 中斷連結」。按下中斷連結，或關閉分頁，即可結束連線。

每個分頁分別配對，且代碼只能使用一次。沒有它，您電腦上的其他程式都無法使用此頁面。會刪除或取代您作品的操作，仍會在頁面中先詢問您，與 AI 面板的做法相同。任何 Slopographic 頁面都可以從命令選擇區連結：按 Ctrl+K（Mac 上為 ⌘K），然後選擇「連結 AI 應用程式…」。

其他 AI 應用程式（Codex、Gemini CLI、Cursor、VS Code、Windsurf、Claude Desktop）的設定說明，會在腳本執行時顯示於此。

ChatGPT 的對話只能連到網際網路上的伺服器，因此目前無法使用這個本機伺服器。ChatGPT 桌面版中的 Codex 可以使用。

對外請求：所有可能發出請求的地方

以下清單對此儲存庫而言是完整的：它來自對每一個 fetch(、XMLHttpRequest、腳本與圖片網址，以及程式碼中每一個外部網址的搜尋。除了下方所述才會載入的分析與廣告腳本之外，應用程式不會載入任何第三方腳本、字型或樣式表。沒有第三方字型，也沒有 iframe。

Cookie 與分析

  • 由網站程式碼保存：同意選擇保存在 localStorage（slop-consent）中，分析、廣告與匯率在您選擇之前都是關閉的。您隨時可以在瀏覽器中清除儲存空間。
  • 網站程式碼不保存的：沒有 Cookie，也沒有帳戶。儲存庫從不寫入 Cookie。
  • Google Analytics：在首頁，程式碼載入時 analytics_storage 設為拒絕。只有在您接受分析後才會開啟。在其他頁面，只有在您接受之後才會載入。
  • Google 自己的腳本在執行時，可能會設定它們自己的 Cookie。這由 Google 決定，而不是 Slopographic 的程式碼。下方的稽核步驟會顯示瀏覽器實際保存了什麼。
  • 廣告：AdSense 只有在您接受廣告後才會載入。拒絕廣告會讓廣告版位保持空白。

離線工作

首次造訪之後，網站自身的檔案會由 Service Worker（service-worker.js，其檔案清單位於 sw-precache.js）保存在 Cache Storage 中。頁面會先透過網路檢查，然後從快取取得，最後才顯示離線頁面。您的檔案不在 Service Worker 的快取中：它們位於您選取的資料夾中，或位於 IndexedDB 中。關閉網路時，應用程式仍可繼續運作。下載項目（上述的模型與字型套件）在首次時需要網路。

如何自行核對

  1. 網路分頁，頁面載入後。開啟應用程式，按 F12（Mac 上為 Cmd+Option+I），然後開啟「網路」分頁。勾選「保留記錄」，再重新載入。查看「網域」欄。一般造訪時，您應該只會看到 slopographic.com，首頁還會有 Google 的分析網域。
  2. 網路分頁，離線。在「網路」分頁中，開啟節流選單並選擇「離線」。重新載入，然後開啟一個檔案、編輯並儲存。應用程式應該仍可運作。需要下載的項目會說明這一點。
  3. 應用程式分頁，儲存空間。在 Chrome 或 Edge 中，開啟「應用程式」分頁。在「儲存空間」下方，查看本機儲存空間、工作階段儲存空間、IndexedDB、Cookie、Cache Storage 與 Service Worker。將您看到的內容與本頁的表格比對。
  4. 接受或拒絕，然後比較。在同意提示列中拒絕分析與廣告，重新載入，然後再次查看「網路」分頁。接著接受它們，看看會出現哪些請求。
  5. 閱讀原始碼。原始碼公開於 GitHub 上的 slopographic 儲存庫。在其中搜尋 fetch(、indexedDB.open、localStorage 或 showDirectoryPicker，即可確認本頁的任何一列。同意程式碼位於 shared/consent/，雲端同步位於 shared/sync/，下載清單位於 shared/library/ 與 aitools/。

本機資料夾（File System Access API）需要 Chrome 或 Edge。Firefox 與 Safari 不提供這項功能，應用程式會在適用的地方說明。
