    Добавьте её в почту

    Gmail
    1. Скопируйте подпись здесь.
    2. В Gmail: Настройки (шестерёнка) › Просмотреть все настройки › Общие › Подпись › Создать новую.
    3. Вставьте её в поле, затем нажмите «Сохранить изменения» внизу.
    Outlook (Windows и Mac)
    1. Скопируйте подпись здесь.
    2. В Outlook: Файл › Параметры › Почта › Подписи (на Mac: Outlook › Настройки › Подписи), затем «Создать».
    3. Вставьте её в поле и нажмите «Сохранить». Выберите её для новых писем и ответов.
    Outlook в браузере
    1. Скопируйте подпись здесь.
    2. Настройки (шестерёнка) › Аккаунт › Подписи › Новая подпись.
    3. Вставьте её, задайте название и сохраните.
    Apple Mail
    1. Скопируйте подпись здесь.
    2. Почта › Настройки › Подписи, выберите аккаунт, затем «+».
    3. Снимите отметку «Всегда использовать шрифт по умолчанию», затем вставьте подпись.

    Изображения показываются только по веб-адресу, который открывается для всех (например, с вашего сайта). Ссылки на соцсети — это слова, а не значки, поэтому каждая почтовая программа показывает их.
