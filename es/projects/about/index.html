Acerca de Slop Projects

Slop Projects planifica el trabajo de una pequeña empresa. Cada proyecto tiene un tablero de columnas, Por hacer, En curso y Hecho para empezar, que puedes renombrar, reordenar y limitar en número de tarjetas, de modo que una columna llena se muestra en rojo. Arrastra tarjetas por el tablero, o muévelas con el teclado. Cada tarea puede tener una descripción, una persona, una prioridad, etiquetas, una lista de verificación, un inicio y un fin, un día límite, un cliente de Slop CRM y las tareas de las que depende. La línea de tiempo muestra las tareas con fecha como barras en una escala de días, semanas o meses, con flechas entre las tareas que dependen unas de otras y una línea para hoy; arrastra una barra para moverla o sus extremos para cambiar las fechas, y las tareas posteriores se desplazan para que nada empiece demasiado pronto. La lista ordena cada tarea por cualquier columna. Cada movimiento y cada eliminación se pueden deshacer. Guarda un proyecto como copia de seguridad en JSON, ábrelo de nuevo donde quieras, o descarga sus tareas en CSV para una hoja de cálculo. Todo se queda en este navegador, y no se sube nada.
