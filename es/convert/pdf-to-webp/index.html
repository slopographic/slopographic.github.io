File convert

Conversor de PDF a WebP

Obtén las páginas de un PDF como imágenes WebP pequeñas para una web o un chat.

Acepta

Documentos PDF (.pdf). Los PDF con contraseña se rechazan. Otros tipos de archivo no se convierten en esta página; el centro de File convert admite todos los tipos que conoce.

Cómo convertir

  1. Cada página se dibuja como imagen a la resolución que elijas (paso 1); escribe un intervalo de páginas para obtener solo algunas.
  2. Cada imagen se guarda después como WebP (paso 2) con la calidad y el tamaño que elijas. Descárgalas una a una o todas en un ZIP.

Tus archivos se quedan en este dispositivo. No se sube nada: la conversión se ejecuta en tu navegador, y el archivo nunca se envía a Slopographic ni a ningún otro servidor.

Preguntas

¿Por qué WebP?

Las imágenes WebP suelen pesar un tercio menos que PNG o JPG con el mismo aspecto, y todos los navegadores actuales las muestran.

¿Puedo conservar el archivo intermedio?

Sí. Abre Opciones y marca Conservar también los archivos intermedios: aparece junto al resultado.

¿Se suben mis archivos?

No. Los dos pasos se hacen en tu navegador, en este dispositivo. Tus archivos no se envían a Slopographic ni a ningún otro servidor.
