Cosa cambia

  • I tuoi file non lasciano mai il dispositivo

    Nulla viene caricato su un server. L’assistente IA scarica il suo modello solo dopo il tuo consenso.

  • Nessun abbonamento, nessun account

    Gratuito. Apri un’app e inizia a lavorare, senza registrazione.

  • Funziona offline

    Dopo la prima visita, un’app continua a funzionare senza connessione.

  • Un solo file di backup

    Il gestore file salva tutto ciò che le tue app conservano in questo browser in un unico file di backup.

Where the number comes from
