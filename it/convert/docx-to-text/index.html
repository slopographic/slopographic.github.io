Convertitore da DOCX a testo

Ricava solo le parole da un documento Word, per la ricerca, uno strumento di traduzione o uno script, senza aprire Word.

Accetta

Documenti Word (.docx). Gli altri tipi di file non vengono convertiti in questa pagina; l’hub di File convert accetta ogni tipo che conosce.

Come convertire

  1. Trascina uno o più file .docx. Ogni paragrafo diventa una riga; le celle delle tabelle arrivano una per riga, nell’ordine di lettura.
  2. Il testo viene salvato in UTF-8, quindi lo svedese, l’arabo, il cinese e ogni altra scrittura restano invariati.

I tuoi file restano su questo dispositivo. Nulla viene caricato: la conversione avviene nel browser e il file non viene mai inviato a Slopographic né a nessun altro server.

Domande

Sono incluse intestazioni e piè di pagina?

No. Il testo è il corpo del documento: i suoi paragrafi, elenchi e tabelle.

E i vecchi file .doc e .ppt?

Questi vecchi formati binari non vengono letti qui. Salvali prima come .docx o .pptx in Word, PowerPoint o LibreOffice.

I miei file vengono caricati?

No. La conversione avviene nel browser, su questo dispositivo. I tuoi file non vengono inviati a Slopographic né a nessun altro server.
