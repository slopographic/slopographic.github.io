# Glossary: Igbo (ig)

Register: Address the user with singular "gị / ị" ("faịlụ gị", "ị nwere ike"), as Microsoft and Google Igbo UIs do. Commands and buttons are bare imperatives with the vowel-harmony ending ("Mepee", "Chekwaa", "Mechie"). Write the dotted vowels ị ọ ụ and ṅ, and the elision apostrophe as ’ (n’efu). Software loanwords in use stay (faịlụ, folda, taabụ). Quality is beta: awaiting native review.
