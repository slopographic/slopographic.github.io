# Glossary: Arabic (ar)

Register: Modern Standard Arabic, right to left. Menu commands use the verbal noun ("حفظ", "فتح", "طباعة"), as Microsoft Office and Acrobat Arabic do; buttons that read as a sentence to the user use the masculine-singular imperative ("افتح التطبيقات", "احتفظ بملفاتي"), and prose addresses the user with masculine singular "ك" ("ملفاتك"), matching shared/i18n/ar.js. Latin brand names stay in Latin script inside the Arabic text.

## PDF editor

Terms chosen for Slop PDF (pdf/i18n/ar/). Kind words that code inserts as {what} or {name} are indefinite nouns ("صورة", "مربع نص") so templates such as "نقل {what}" and "المحدد: {what}" fit any of them. Counts carry #one/#two/#few/#many forms where Arabic needs them (#one and #two without the digit: "صفحة واحدة", "صفحتان"). The page-list words all, odd, even, last are syntax and stay English; the page-number styles ("Page 1 of N") stay English because that text is stamped into the PDF.

## One term per concept across apps

Chosen in the review pass so the same idea reads the same in every app. Brand names (Sloppo, PhotoSlop, Slopographic, Slopify and every "Slop …" name) stay in Latin script. Back arrows are written for a right-to-left page: "→ الفواتير" (the arrow points right, toward the previous page); "←" is kept between a source and a target ("{from} ← {to}") and for physical arrow keys. A breadcrumb or menu path keeps the English "›" and "◂" (both point left in a right-to-left line, toward the next item). Counts follow CLDR: #zero "لا …" or "لم يتم … أي …", #one and #two without the digit, #few (3 to 10) plural with the number, #many (11 to 99) singular accusative with the number ("{n} صفحةً"), bare other (100 and up) singular without tanween ("{n} صفحة"). Tanween is written "ًا" (not "اً"), except after a final alef ("كاميراً").
