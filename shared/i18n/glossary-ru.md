# Glossary: Russian (ru)

Register: address the user as «вы» (lowercase), as Microsoft Office, Google Workspace and Adobe Acrobat do in Russian. Buttons and menu commands are infinitives («Сохранить», «Открыть»); menu titles and some short commands are nouns as in Office («Файл», «Правка», «Вид», «Экспорт», «Печать»). Running text uses the «вы» imperative («Выберите», «Подключите»). Quotes are «ёлочки». Keep labels short: Russian runs about 20–30% longer than English. Write «ё» where Office does («всё», «учётная запись»).
