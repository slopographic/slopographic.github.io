# Glossary: Ukrainian (uk)

Register: address the user as «ви» (lowercase), as Microsoft Office, Google Workspace and Adobe Acrobat do in Ukrainian. Buttons and commands are infinitives («Зберегти», «Відкрити»); menu titles are nouns as in Office («Файл», «Редагування», «Вигляд», «Довідка»). Running text uses the «ви» imperative («Виберіть», «Підключіть»). Use «застосунок» for app (current Microsoft and Google usage), not «додаток». Quotes are «ялинки»; the apostrophe is ’. Keep labels short.
