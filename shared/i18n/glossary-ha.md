# Glossary: Hausa (ha)

Register: Address the user as singular masculine "ka" ("fayilolinka", "kana iya"), the default in Microsoft and Google Hausa UIs. Commands and buttons are bare imperatives ("Buɗe", "Ajiye", "Soke"). Use the hooked letters ɓ ɗ ƙ ƴ and write the glottal stop as ’ (na’ura, ma’aji). Software loanwords in use stay (fayil, foldar, burauza). Quality is beta: awaiting native review.
