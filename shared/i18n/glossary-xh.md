# Glossary: Xhosa (xh)

Register: Address the user in the singular (possessives "-kho": "iifayile zakho"), as Microsoft and Google isiXhosa UIs do. Commands and buttons are bare imperatives ("Vula", "Gcina", "Rhoxisa"). Loanwords and brand names take a hyphenated class prefix (i-app, ii-app, i-Chrome, kwi-Slop Drive); keep the brand itself unchanged after the hyphen. Quality is beta: awaiting native review.
