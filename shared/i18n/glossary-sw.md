# Glossary: Swahili (sw)

Register: Address the user as singular "wewe" (verbs and possessives: "faili zako", "unaweza"), as Microsoft and Google Swahili UIs do. Commands and buttons are bare singular imperatives ("Fungua", "Hifadhi", "Ghairi"). English loanwords that speakers actually use for software stay (faili, folda, menyu, fonti). Quality is beta: awaiting native review.
