# Glossary: Yoruba (yo)

Register: Address the user with singular "o / rẹ" ("àwọn fáìlì rẹ", "o lè"), as Microsoft and Google Yorùbá UIs do; "ẹ" is used only in the set phrase "ẹ ṣé". Commands and buttons are bare imperatives ("Ṣí", "Fi pamọ́", "Fagilé"). Write full tone marks and underdots (ẹ ọ ṣ) everywhere, including on loanwords (fáìlì, fódà, áàpù). Quality is beta: awaiting native review.
