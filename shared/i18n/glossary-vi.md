# Glossary: Vietnamese (vi)

Register: address the user as bạn, as Google Workspace and Microsoft 365 in Vietnamese do; buttons are short verbs with no polite particles (Mở, Lưu, Xuất), sentences may start with Hãy when asking the user to act. Use the modern tone-mark placement Microsoft uses (hóa đơn, hủy, thụy). Brand and app names stay as they are.

The terms the shared chrome (shared/i18n/vi.js) and the app tables use. Add a term here when you choose one.
