# Glossary: Amharic (am)

Register: Sentences address the user with the polite second person (እርስዎ: "ፋይሎችዎ", "ይምረጡ"), the register Microsoft and Google Amharic use for prose. Commands and buttons are short masculine-singular imperatives ("ክፈት", "አስቀምጥ", "ዝጋ"), as in Microsoft Amharic menus. Sentences end with "።", lists use "፣", and quotes use «…». Quality is beta: awaiting native review.
