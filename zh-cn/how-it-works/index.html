Slopographic 的工作原理

这些应用在你的浏览器中运行。本页列出它们使用的浏览器功能、它们可能发出的每一个网络请求，以及保存在你设备上的内容，方便你自己核实每一项说法。本页的每一条陈述都已对照公开代码仓库中的源代码进行核对。

简要版本

  • 你的文件留在你的设备上。这些应用没有接收文件的服务器，也没有任何代码会上传你打开或保存的文件。唯一的例外是：你允许 AI 按钮把一份副本发送到你自己连接的 AI 服务。
  • 你在磁盘上选择的文件，通过浏览器的 File System Access API 在你选定的文件夹中读写。参见 浏览器 API。
  • 数据保存在此设备上浏览器自己的存储中（IndexedDB 和 localStorage）。参见 保存的内容。
  • 部分请求会离开本站，但仅限于 每一个对外请求 中列出的情况：你确认的下载、你连接的云端备份、你用自己的密钥连接的 AI 服务、你开启的汇率，以及你接受的分析或广告。
  • AI 按钮可使用你设备上的模型、你自己电脑上的服务器（例如 Ollama 或 LM Studio），或你自己的 Claude、ChatGPT 或 Gemini 等服务密钥。使用密钥时，你提出的问题会从浏览器直接发送到该服务商。参见 AI 按钮。
  • 首页每次访问时都会加载 Google Analytics 代码，分析功能设为拒绝。其他页面只有在你接受分析后才会加载。只有在你接受广告后才会加载广告。

通俗地说

我的文件去了哪里？

哪里也不去。当你打开照片、PDF 或电子表格时，应用会在此浏览器标签页中读取它。没有上传步骤，也没有可以接收文件的 Slopographic 服务器。你保存的内容会进入你自己的磁盘，或此设备上此浏览器的存储中。只有当你连接自己的密钥 AI 服务并允许时，才会有副本发送到该服务（参见 AI 按钮）。

为什么应用有时会下载一些东西？

部分功能需要一个大多数人从不使用的大文件：AI 模型（用于移除背景、识别文字或转录语音）、视频引擎（用于转换视频），或用于其他书写系统的字体。这些文件只在你使用该功能时才会获取，并且会在应用告诉你它是什么、有多大之后才开始。这些文件会保存在浏览器中，因此只需下载一次。你自己的文件从不包含在该请求中。

离线也能用吗？

可以，首次访问之后即可。网站自身的文件由浏览器保存，因此应用无需连接网络即可打开并工作。只有你尚未下载的内容（模型或字体）才需要网络。

需要安装什么吗？

不需要。在手机、平板或电脑上的浏览器中打开应用即可开始使用。首次访问后，它在没有网络时也能继续工作。想在主屏幕上放一个图标？在 iPhone 或 iPad 上，点按“分享”，然后选择“添加到主屏幕”。在 Android 上，打开浏览器菜单，点按“添加到主屏幕”。在电脑上，点击地址栏中的安装图标。你无需 App Store 或 Google Play，你的文件也始终保留在你的设备上。

AI 按钮会发送什么，发往哪里？

这取决于你选择的模型。设备上的模型（需要 WebGPU，且只下载一次）在此标签页内作答，你提出的任何问题都不会离开设备。Ollama、LM Studio 及类似服务器运行在你自己的电脑上，或你在网络中设置的一台电脑上。使用你自己的 Claude、ChatGPT、Gemini、OpenRouter 或 Groq 等服务密钥时，你的消息会从浏览器直接发送到该服务商，中间没有 Slopographic 服务器，并适用其条款和价格。只有在面板询问并且你允许后，文件副本或你作品的图片才会被发送（你可以针对一次请求、一次访问或始终允许，并可在 AI 权限中撤销）。由 AI 生成或修改的图片（生成图片、用 AI 编辑）需要你连接的图像服务，例如使用你自己密钥的 OpenAI、Gemini 或 OpenRouter：浏览器本身无法绘制这些图片。设备上的模型和你自己电脑上的模型不收取费用；Gemini、Groq 和 Mistral 提供免费套餐，OpenRouter 提供免费模型（面板会标注“免费”）。密钥会保留在此标签页中直到你关闭它，只有当你勾选“在此设备上记住”时，才会保存在此浏览器中。对于 OpenRouter，你也可以点按“使用 OpenRouter 登录”，而不必粘贴密钥：你的浏览器会前往 openrouter.ai，你在那里允许访问，返回时本页会直接向 OpenRouter 为此浏览器请求一个密钥。登录过程直接在你的浏览器与 OpenRouter 之间进行，不经过 Slopographic 的服务器。该密钥从你自己的 OpenRouter 额度中扣费，保存方式与粘贴的密钥完全相同；你可以在 openrouter.ai/settings/keys 设置上限或撤销它，“忘记密钥”则会将其从此浏览器中移除。

AI 代理可以使用这些应用吗？

在支持 WebMCP 的浏览器中可以：浏览器中的助手，或通过浏览器扩展连接到你电脑的 AI 代理，都可以运行应用的命令、File convert 转换和工作流，并打开、保存或下载文件。它通过 ID 引用你的文件；工作在此标签页中运行，应用不上传任何内容，但代理能看到工具返回的结果。任何会删除或替换你作品的操作都会先询问你。WebMCP 仍是早期草案：Chrome 以试用版提供（版本 149 至 156）并需通过标志开启，Edge 需通过标志开启，Firefox 和 Safari 尚不支持。你可以在“设置”中关闭它，或在“帮助”、“AI 代理”中关闭。

我能自己核实吗？

可以。源代码是公开的，下方各节列出了应用使用的每一项浏览器功能和它们可能发出的每一个请求，并附有负责该功能的文件。你也可以打开浏览器的开发者工具，进入“网络”标签页观察：打开和保存你的文件不会发送任何内容。

从 Claude Code 和其他 AI 应用中使用 Slopographic

即将推出：你电脑上的 AI 应用，例如 Claude Code、Codex、Cursor、VS Code 或 Claude Desktop，可以使用你在浏览器中打开的 Slopographic 应用：它的真实命令、转换和工作流，你的文件输入，结果则以文件形式输出到你的电脑上。它通过 Slopographic MCP 服务器运行，这是 AI 应用在你电脑上启动的一个小程序。除 AI 应用本身外，无需账户，也无需安装其他任何东西。

  1. Claude Code：输入 /plugin marketplace add slopographic/claude-plugin，然后输入 /plugin install slopographic@slopographic。只需做一次。
  2. 输入 /slopographic:slop-connect（如果愿意，可加上应用名称，例如 photoslop）。Claude Code 会在你的浏览器中打开 Slopographic，并显示一个简短的代码。
  3. Chrome 会询问一次，是否允许此网站使用此设备上的应用和服务。请选择允许：这是页面与你电脑上的 Claude Code 通信的方式。页面只与你自己的电脑（127.0.0.1）通信，不与你的网络通信。
  4. 在页面中输入代码。随后页面的角落会显示“Claude Code 已连接 · 断开连接”。点击“断开连接”或关闭标签页即可结束连接。

每个标签页单独配对，且代码只能使用一次。没有它，你电脑上的其他任何程序都无法使用该页面。会删除或替换你作品的操作仍会在页面中询问你，与 AI 面板中一样。任何 Slopographic 页面都可以从命令面板连接：按 Ctrl+K（Mac 上为 ⌘K），然后选择“连接 AI 应用…”。

其他 AI 应用（Codex、Gemini CLI、Cursor、VS Code、Windsurf、Claude Desktop）的设置会在脚本运行时显示在此处。

ChatGPT 对话只能访问互联网上的服务器，因此目前无法使用此本地服务器。ChatGPT 桌面应用中的 Codex 可以使用。

Cookie 和分析

  • 由网站代码保存：在 localStorage（slop-consent）中保存的同意选择，在你选择之前分析、广告和汇率均为关闭。你可以随时在浏览器中清除存储。
  • 网站代码不保存：没有 Cookie，也没有账户。代码仓库从不写入 Cookie。
  • Google Analytics：在首页，标签加载时 analytics_storage 设为拒绝。只有当你接受分析时才会开启。在其他页面，只有在你接受后才会加载。
  • Google 自己的脚本在运行时可能会设置它们自己的 Cookie。这由 Google 决定，而不是由 Slopographic 的代码决定。下面的审计步骤会显示浏览器实际保存了什么。
  • 广告：AdSense 只有在你接受广告后才会加载。拒绝广告会让广告位保持空白。

离线工作

首次访问之后，网站自身的文件会由 Service Worker 保存在 Cache Storage 中（service-worker.js，其文件列表位于 sw-precache.js）。页面先通过网络检查，然后从缓存中读取，再显示离线页面。你的文件不在 Service Worker 缓存中：它们位于你选择的文件夹中，或 IndexedDB 中。在断网时，应用仍可继续工作。下载内容（上面列出的模型和字体包）首次需要网络。

如何自行核实

  1. 网络标签页，页面加载后。打开应用，按 F12（Mac 上为 Cmd+Option+I），然后打开“网络”标签页。勾选“保留日志”，然后刷新。查看“域”一列。普通访问时，你应该只看到 slopographic.com，首页上另加 Google 的分析域名。
  2. 网络标签页，离线。在“网络”标签页中，打开节流菜单并选择“离线”。刷新，然后打开一个文件，编辑并保存。应用应该仍能工作。需要下载的内容会有相应提示。
  3. 应用标签页，存储。在 Chrome 或 Edge 中，打开“应用”标签页。在“存储”下查看本地存储、会话存储、IndexedDB、Cookie、Cache Storage 和 Service Worker。将你看到的内容与本页中的表格进行比对。
  4. 接受或拒绝，然后比对。在同意横条中拒绝分析和广告，刷新，然后再次检查“网络”标签页。然后接受它们，看看会出现哪些请求。
  5. 阅读源代码。代码公开在 GitHub 上的 slopographic 代码仓库中。搜索 fetch(、indexedDB.open、localStorage 或 showDirectoryPicker 即可确认本页中的任何一行。同意代码位于 shared/consent/，云端同步位于 shared/sync/，下载列表位于 shared/library/ 和 aitools/。

本地文件夹（File System Access API）需要 Chrome 或 Edge。Firefox 和 Safari 不提供此功能，应用在适用的地方会说明。
