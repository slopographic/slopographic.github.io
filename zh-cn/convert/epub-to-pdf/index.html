File convert

EPUB 转 PDF 转换器

打印一本书、用 PDF 阅读器阅读，或发给没有电子阅读器的人。

支持的输入

EPUB 电子书（.epub）。本页面不转换其他文件类型；File convert 入口页支持它所知的每种类型。

转换方法

  1. 第 1 步按阅读顺序读取各章，并将其写为 Markdown，因此标题、粗体、斜体、列表和引用都保留其含义。
  2. 第 2 步用 Slop Docs 引擎把 Markdown 排版到页面上：可选择 A4 或 US Letter，以及无衬线、衬线或等宽字体。PDF 中的文字是真正的文字，可搜索和复制。

你的文件保留在本设备上。不会上传任何内容：转换在你的浏览器中完成，文件从未发送到 Slopographic 或其他任何服务器。

常见问题

能转换商店里的书吗？

只有没有 DRM 的书才可以。带 DRM 的书，其文字仍是加密的，因此页面会说明这一点，并且不转换任何内容。

PDF 中有图片吗？

没有，图片会变为方括号中的说明。表格保持为表格的 Markdown 文字。

能保留 Markdown 吗？

能。打开“选项”并勾选“同时保留中间文件”。

我的文件会被上传吗？

不会。转换在你的浏览器中、在这台设备上运行。你的文件不会发送到 Slopographic 或任何其他服务器。
