検証

Slopographic の仕組み

アプリはお使いのブラウザー内で動作します。このページでは、アプリが使うブラウザー機能、アプリが送信しうるすべてのネットワーク リクエスト、デバイスに保存される内容を一覧にしています。ご自身で各記述を確認できるようにするためです。ここに書かれた内容はすべて、公開リポジトリのソースコードと照合して確認しています。

要点

  • ファイルはお使いのデバイスに残ります。ファイルを受け取るアプリのサーバーはなく、開いたファイルや保存したファイルをアップロードするコードもありません。唯一の例外は、ご自身で接続した AI サービスへ、AI ボタンが送信することを許可したコピーです。
  • ディスク上で選んだファイルは、ブラウザーの File System Access API を通じて、選んだフォルダー内で読み書きされます。ブラウザー APIを参照してください。
  • データは、このデバイス上のブラウザー自身のストレージ（IndexedDB と localStorage）に保存されます。保存される内容を参照してください。
  • サイトの外へ出るリクエストもありますが、すべての送信リクエストに挙げた場合に限られます。具体的には、確認したダウンロード、接続したクラウド バックアップ、ご自身のキーで接続した AI サービス、有効にした為替レート、同意した分析または広告です。
  • AI ボタンは、お使いのデバイス上のモデル、Ollama や LM Studio のようにご自身のコンピューター上で動くサーバー、または Claude、ChatGPT、Gemini などのサービス用にご自身で用意したキーで動作します。キーを使う場合、入力した内容はブラウザーから直接そのプロバイダーに送られます。AI ボタンを参照してください。
  • ホームページは、訪問のたびに、分析を拒否に設定した状態の Google アナリティクスのコードを読み込みます。その他のページは、分析に同意した後にのみ読み込みます。広告は、広告に同意した後にのみ読み込まれます。

わかりやすい説明

ファイルはどこへ行くのですか？

どこにも行きません。写真、PDF、スプレッドシートを開くと、アプリはこのブラウザーのタブの中でそれを読み込みます。アップロードの手順はなく、ファイルを受け取る Slopographic のサーバーもありません。保存した内容は、お使いのディスク、またはこのデバイスのこのブラウザーのストレージに保存されます。AI サービスをご自身のキーで接続し、許可した場合にのみ、そのサービスにコピーが送られます（AI ボタンを参照してください）。

アプリがときどき何かをダウンロードするのはなぜですか？

ほとんどの人が使わない大きなファイルが必要な機能があるためです。AI モデル（背景の削除、文字の認識、音声の書き起こしのため）、動画エンジン（動画の変換のため）、他の文字体系用のフォントなどです。これらは、その機能を使ったときにのみ取得されます。取得前にアプリが内容と大きさを表示します。また、ブラウザーに保存されるため、同じ取得は一度だけ行われます。お使いのファイルがそのリクエストに含まれることはありません。

オフラインでも使えますか？

はい、初回の訪問後は使えます。サイト自身のファイルはブラウザーに保存されるため、接続がなくてもアプリは開いて動作します。まだ行っていないダウンロード（モデルやフォント）だけがネットワークを必要とします。

何かインストールする必要はありますか？

いいえ。スマートフォン、タブレット、パソコンのブラウザーでアプリを開くだけで使い始められます。初回の訪問後は、インターネットに接続していなくても動作を続けます。ホーム画面にアイコンを置きたい場合は、iPhone や iPad では「共有」をタップし、「ホーム画面に追加」を選びます。Android では、ブラウザーのメニューを開いて「ホーム画面に追加」をタップします。パソコンでは、アドレスバーのインストール アイコンをクリックします。App Store や Google Play は必要なく、ファイルはお使いのデバイスに残ります。

AI ボタンは何を、どこへ送るのですか？

それは選んだモデルによって異なります。デバイス上のモデル（WebGPU が必要で、一度だけダウンロードされます）は、このタブ内で応答するため、入力した内容がデバイスの外に出ることはありません。Ollama、LM Studio などの類似サーバーは、お使いのコンピューター上、またはご自身で設定したネットワーク内のコンピューター上で動作します。Claude、ChatGPT、Gemini、OpenRouter、Groq などのサービス用にご自身のキーを使うと、入力した内容はブラウザーから直接そのプロバイダーに送られます。間に Slopographic のサーバーは入りません。そのプロバイダーの利用規約と料金が適用されます。ファイルのコピーや作業内容の画像は、パネルが確認を求め、許可した後にのみ送信されます（一回のリクエスト、一回の訪問、または常に許可できます。取り消しは AI の権限で行えます）。AI が作成または変更した画像（「画像を生成」、AI で編集）には、ご自身で接続した画像サービス（OpenAI、Gemini、OpenRouter などをご自身のキーで利用）が必要です。ブラウザー内で描画されることはありません。デバイス上のモデルとご自身のコンピューター上のモデルは無料です。Gemini、Groq、Mistral には無料枠があり、OpenRouter には無料のモデルがあります（パネルで「Free」と表示されます）。キーは、タブを閉じるまでこのタブに保存されます。「このデバイスに保存」にチェックを入れた場合にのみ、このブラウザーに保存されます。OpenRouter では、キーを貼り付ける代わりに「OpenRouter でサインイン」を押すこともできます。ブラウザーは openrouter.ai に移動し、そこでアクセスを許可すると、戻ってきたこのページが、このブラウザー用のキーを OpenRouter 自身に要求します。サインインはブラウザーと OpenRouter の間で直接行われ、Slopographic のサーバーを経由することはありません。キーは OpenRouter のご自身のクレジットから支払われ、貼り付けたキーと同じように保存されます。openrouter.ai/settings/keys で上限を設定したり取り消したりできます。「キーを削除」を押すと、このブラウザーからキーが削除されます。

AI エージェントはアプリを使えますか？

WebMCP に対応したブラウザーでは使えます。ブラウザー内のアシスタント、またはブラウザー拡張機能で接続されたご自身のコンピューター上のエージェントは、アプリのコマンド、File convert の変換、ワークフローを実行したり、ファイルを開く、保存する、ダウンロードするといった操作を行ったりできます。エージェントはファイルを ID で参照します。処理はこのタブ内で行われ、アプリは何もアップロードしませんが、エージェントはツールが返す内容を見ることができます。作業内容を削除または置き換える操作は、必ず事前に確認を求めます。WebMCP はまだ初期の草案です。Chrome では試験版（バージョン 149 から 156）として提供され、Edge ではフラグの背後にあり、Firefox と Safari ではまだ提供されていません。設定、またはヘルプの「AI エージェント」でオフにできます。

自分で確認することはできますか？

はい。ソースコードは公開されており、以下のセクションには、アプリが使うすべてのブラウザー機能と送信しうるすべてのリクエストを、該当するファイルとともに掲載しています。ブラウザーの開発者ツールを開いて Network タブを見ることもできます。ファイルを開いたり保存したりしても、何も送信されないことが確認できます。

Claude Code などの AI アプリから Slopographic を使う

近日公開: Claude Code、Codex、Cursor、VS Code、Claude Desktop などの、お使いのコンピューター上の AI アプリは、ブラウザーで開いている Slopographic アプリを使えるようになります。実際のコマンド、変換、ワークフローを利用でき、ファイルはコンピューターとの間でファイルとして出し入れされます。Slopographic MCP サーバー（AI アプリがコンピューター上で起動する小さなプログラム）を経由して動作します。アカウントは不要で、AI アプリ以外にインストールするものもありません。

  1. Claude Code: /plugin marketplace add slopographic/claude-plugin と入力し、続けて /plugin install slopographic@slopographic を入力します。これは一度だけ行います。
  2. /slopographic:slop-connect と入力します（必要なら photoslop のようにアプリ名を追加してください）。Claude Code がブラウザーで Slopographic を開き、短いコードを表示します。
  3. Chrome は、このサイトがこのデバイス上のアプリやサービスを使えるかどうかを、最初に一度確認します。許可を選んでください。これにより、ページがお使いのコンピューター上の Claude Code に接続できます。ページが通信するのはお使いのコンピューター（127.0.0.1）だけで、ネットワーク上の他の機器とは通信しません。
  4. ページにコードを入力します。すると、ページの隅に「Claude Code に接続中 · 切断」と表示されます。「切断」を押すか、タブを閉じると接続を終了できます。

タブごとに個別にペアリングされ、コードは一度だけ使えます。このコードがなければ、コンピューター上の他のものはページを使えません。作業内容を削除または置き換える操作は、AI パネルと同様に、ページ内でも確認を求めます。どの Slopographic ページからも、コマンド パレットで接続できます。Ctrl+K（Mac では ⌘K）を押し、「AI アプリに接続…」を選んでください。

その他の AI アプリ（Codex、Gemini CLI、Cursor、VS Code、Windsurf、Claude Desktop）の設定は、スクリプトが実行されるとここに表示されます。

ChatGPT のチャットは、インターネット上のサーバーにしか接続できないため、このローカル サーバーはまだ使えません。ChatGPT デスクトップ アプリの Codex は使えます。

Cookie と分析

  • サイトのコードが保存するもの: 同意の選択を localStorage に保存します（slop-consent）。分析、広告、レートは、選ぶまではオフです。ストレージはブラウザーでいつでも消去できます。
  • サイトのコードが保存しないもの: Cookie もアカウントもありません。リポジトリが Cookie を書き込むことはありません。
  • Google アナリティクス: ホームページでは、analytics_storage を拒否に設定した状態でタグが読み込まれます。分析に同意したときにのみオンになります。その他のページでは、同意した後にのみ読み込まれます。
  • Google 自身のスクリプトは、実行時に独自の Cookie を設定することがあります。それは Slopographic のコードではなく Google が決めることです。以下の確認手順で、ブラウザーが実際に何を保存しているかを確認できます。
  • 広告: AdSense は、広告に同意した後にのみ読み込まれます。広告を拒否すると、広告枠は空のままになります。

オフラインでの利用

初回の訪問後、サイト自身のファイルは、サービス ワーカー（service-worker.js。ファイル一覧は sw-precache.js）によって Cache Storage に保存されます。ページはまずネットワークで確認し、次にキャッシュから読み込み、最後にオフライン ページを表示します。ご自身のファイルはサービス ワーカーのキャッシュには入りません。選んだフォルダーか IndexedDB にあります。ネットワークがオフでもアプリは動作を続けます。ダウンロード（上記のモデルやフォント パック）は、初回だけネットワークが必要です。

ご自身で確認する方法

  1. Network タブ（ページを読み込んだ状態で）。アプリを開き、F12 キー（Mac では Cmd+Option+I）を押して Network タブを開きます。「Preserve log」（ログを保持）にチェックを入れてから再読み込みします。Domain 列を確認してください。通常の訪問では、slopographic.com だけが表示され、ホームページではさらに Google の分析ドメインが表示されます。
  2. Network タブ、オフライン。Network タブのスロットリング メニューで「Offline」を選びます。再読み込みし、ファイルを開いて編集し、保存します。アプリは動作するはずです。ダウンロードが必要なものは、その旨が表示されます。
  3. Application タブ、ストレージ。Chrome または Edge で Application タブを開きます。Storage の下で、Local storage、Session storage、IndexedDB、Cookies、Cache Storage、Service workers を確認します。見えるものを、このページの表と比べてください。
  4. 同意または拒否をして比較する。同意バナーで分析と広告を拒否し、再読み込みして Network タブを再度確認します。その後で同意し、どのリクエストが現れるかを確認します。
  5. ソースを読む。コードは、GitHub の slopographic リポジトリで公開されています。このページの各項目を確認するには、fetch(、indexedDB.open、localStorage、showDirectoryPicker を検索してください。同意のコードは shared/consent/、クラウド同期は shared/sync/、ダウンロード一覧は shared/library/ と aitools/ にあります。

ローカル フォルダー（File System Access API）には Chrome または Edge が必要です。Firefox と Safari はこれを提供していないため、該当する場合はアプリにその旨が表示されます。
