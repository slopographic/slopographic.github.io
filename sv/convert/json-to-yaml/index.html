JSON till YAML-konverterare

Gör om JSON till YAML som människor kan läsa och redigera: inga klammerparenteser och inga citattecken där de inte behövs.

Tar emot

JSON (.json). Andra filtyper konverteras inte på den här sidan; navet i File convert tar emot alla typer det känner till.

Så konverterar du

  1. JSON-texten kontrolleras först; ett fel rapporteras med rad och kolumn. YAML-texten skrivs av js-yaml, med citattecken runt strängar bara där YAML kräver det.
  2. Nycklarnas ordning behålls.

Dina filer stannar på den här enheten. Inget laddas upp: konverteringen körs i webbläsaren, och filen skickas aldrig till Slopographic eller till någon annan server.

Frågor

Blir YAML-texten samma JSON igen när den läses tillbaka?

Ja. YAML till JSON ger tillbaka samma data.

Kan jag skriva eller klistra in text i stället för en fil?

Ja. Skriv eller klistra in i rutan under konverteraren, så uppdateras förhandsgranskningen medan du skriver.

Laddas mina filer upp?

Nej. Konverteringen körs i webbläsaren, på den här enheten. Dina filer skickas inte till Slopographic eller till någon annan server.
